---

## 🚀 About the Project
**CineCookbook** is a feature-rich, interactive web application that bridges the gap between cinema and gastronomy. It allows food and film enthusiasts to discover, create, and share recipes inspired by iconic movies and TV shows. 

Built for the **Bugbusters** hackathon track, this application features a heavily optimized, bug-free state management architecture (`RecipeContext`), persistent local caching, reliable engagement voting logic, and a lightning-fast cloud media pipeline.

---

## ✨ Key Features
* **🎬 Movie-Inspired Recipes:** Browse curated recipes tied directly to legendary cinematic masterpieces.
* **☁️ Cloudinary Media Pipeline:** Instant cloud-based image uploads, automated transformations, and global CDN delivery for crystal-clear recipe visuals.
* **🔄 Robust State Management (`RecipeContext`):** Seamless client-side state handling with persistent synchronization in `localStorage`.
* **👍 Real-Time Voting & Interaction:** Clean, bug-free like/dislike voting mechanics ensuring accurate user engagement metrics.
* **📱 Responsive Design:** Modern, sleek user interface optimized seamlessly for both mobile and desktop screens.

---

## 🛠️ Tech Stack
* **Frontend / Framework:** [Next.js](https://nextjs.org/) (React)
* **Styling:** Tailwind CSS / Modern CSS Modules
* **Media Management & CDN:** [Cloudinary Upload Widget & APIs](https://cloudinary.com/)
* **State & Persistence:** React Context API & Browser `localStorage`

---

## ☁️ How We Use Cloudinary
CineCookbook relies heavily on Cloudinary to handle all media assets efficiently:
1. **Optimized Uploads:** Users leverage Cloudinary's powerful upload widgets to seamlessly add high-quality food photography when submitting recipes.
2. **Automated Delivery:** Images are dynamically served through Cloudinary's global CDN in next-gen formats (WebP/AVIF) for blazing-fast load speeds.
3. **Dynamic Transformations:** URL-based cropping and formatting parameters ensure all recipe thumbnails maintain uniform aspect ratios and sharp visual presentation regardless of upload dimensions.
